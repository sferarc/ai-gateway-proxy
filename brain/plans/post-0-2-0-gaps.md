# Gaps after 0.2.0

Open unknowns found by reading [[architecture/proxy]] and [[architecture/streaming]] as of main 50d6250, after #59 to #61, #64 and #66 landed. [[roadmap]] has no open item, so these are the candidates for the next round. Gateway redirects and non-object `afterResponse` results are closed by #64 ([[decisions/2026-10-21-fail-closed-redirects-and-hook-results]]) and are not listed. Each names its source and what blocks it. No item here needs a paid gateway call to write; only item 3 needs one to settle.

1. **Gateway path matching beyond the folded spellings.** Since #59, and with the spellings pinned by #66, the `language-model` and batch read path checks fold case, percent-encoding, repeated and trailing slashes and `;` parameters. Whether the gateway routes any other spelling, or the same spellings as one route, is unverified, and a spelling the gateway serves but the fold misses would skip the hooks. Source: the #59 review caveat that the gateway's path match is unchecked, and the decision note #59 added, `decisions/2026-10-21-language-model-path-runs-hooks`. Blocker: the gateway docs or a recorded request, since probing it costs money. Until then the fold is the whole guarantee. #66 narrowed this item to the gateway's own path matching: the proxy side is covered by tests. The folded spellings are pinned in `src/proxy.test.ts` (`folds the path ... to a language model call`, `... to a batch read and runs no hook`). The gateway's own routing and the choice of the fail-closed alternative stay open. The fail-closed alternative from the #59 review is to skip hooks only on known non-language model paths and batch reads, and run them everywhere else; it needs no gateway knowledge but changes which calls run hooks.
2. **Hooks for non-language-model calls.** Embedding, image, video, speech, transcription, reranking, decision and batch start calls run no hook, so an operator cannot meter or audit them through the proxy. Source: step 6 of [[architecture/proxy]]. Blocker: the owner, since per-kind hook types are a public contract change; a first step is a hook that receives the raw request and response for those paths.
3. **Non-language model kinds are untested against the real gateway.** The keyless tests use fakes shaped after `@ai-sdk/gateway` 4.x, and `src/integration.test.ts` calls only `generateText` and `streamText`. Embedding, image, video and batch behavior through the proxy rests on reading the client, not on observed gateway responses. Source: [[development/testing]]. Blocker: a gateway key and paid calls, which are the owner's ([[decisions/2026-10-08-no-gateway-key-in-ci]]).
4. **Hook results are not validated.** An `afterResponse` result that is an object with missing or wrong-typed fields is serialised as returned, and on a stream the missing fields are left out of the rewritten `finish` event. Arrays and non-objects are rejected, and `undefined` and `null` fall back to the upstream body (see [[decisions/2026-10-21-fail-closed-redirects-and-hook-results]]); the object-field and streaming cases remain. Source: "Hook result without stream metadata" in [[architecture/streaming]] and step 9 of [[architecture/proxy]]. Blocker: the owner, since rejecting such a result instead of forwarding it is a contract choice.

Update this note, and [[roadmap]] once it has items again, when an item lands.
