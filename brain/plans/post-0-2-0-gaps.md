# Gaps after 0.2.0

Open unknowns found by reading [[architecture/proxy]] and [[architecture/streaming]] as of main 50d6250, after #59 to #61, #64 and #66 landed. [[roadmap]] has no open item, so these are the candidates for the next round. Gateway redirects and non-object `afterResponse` results are closed by #64 ([[decisions/2026-10-21-fail-closed-redirects-and-hook-results]]) and are not listed. Each names its source and what blocks it. No item here needs a paid gateway call to write; only item 3 needs one to settle.

1. **Gateway path matching beyond the folded spellings.** Closed: the owner chose the fail-closed alternative in #70 on 2026-10-26. The hooks now run on every path except an exact list of the paths `@ai-sdk/gateway` uses for other calls and job reads, so a spelling the gateway might serve no longer needs to be known ([[decisions/2026-10-26-fail-closed-path-matching]], [[architecture/proxy]] step 6). The gateway's own routing stays unverified, and now only decides whether an unusual spelling of a real non-language-model call breaks a hook typed for language model calls.
2. **Hooks for non-language-model calls.** Closed: on the owner's #70 decision of 2026-10-26, embedding, image, video, speech, transcription, reranking, decision and batch start calls run the new optional `beforeRawRequest` and `afterRawResponse`, which receive the parsed body and the client response untyped ("Raw hooks" in [[architecture/proxy]]). Per-kind typed hooks are not built; they would need the gateway's response shapes, which item 3 leaves unobserved.
3. **Non-language model kinds are untested against the real gateway.** The keyless tests use fakes shaped after `@ai-sdk/gateway` 4.x, and `src/integration.test.ts` calls only `generateText` and `streamText`. Embedding, image, video and batch behavior through the proxy rests on reading the client, not on observed gateway responses. `src/non-language-model.test.ts` pins the proxy side with a fake gateway (path, auth, unchanged body, no hook), which leaves the real gateway's responses unobserved. The same paid check would settle whether the old default `/v1/ai` served version 4 bodies correctly, which no call has observed ([[decisions/2026-10-28-default-base-url-v4]]). Source: [[development/testing]]. Blocker: a gateway key and paid calls, which are the owner's ([[decisions/2026-10-08-no-gateway-key-in-ci]]).
4. **Hook results are not validated.** Closed: on the owner's #70 decision of 2026-10-26, an `afterResponse` result with a missing or wrong-typed field is rejected, as a 500 naming the field on a non-streamed request and by forwarding the original `finish` event on a stream ([[decisions/2026-10-26-strict-after-response-results]]). The check stops at the fields the proxy and the client read; the shape of each `content` part beyond its `type` is not checked.

Items 1, 2 and 4 were decided by the owner in #70 on 2026-10-26 and built in one pull request; item 3 remains open and needs the owner.

Update this note, and [[roadmap]] once it has items again, when an item lands.
