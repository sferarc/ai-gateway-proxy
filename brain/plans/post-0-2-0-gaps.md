# Gaps after 0.2.0

GitHub Issues are the source of truth for the open item here; this note keeps the history of the round.

Open unknowns found by reading [[architecture/proxy]] and [[architecture/streaming]] as of main 50d6250, after #59 to #61, #64 and #66 landed. At the time [[roadmap]] had no open item, so these were the candidates for the next round. Gateway redirects and non-object `afterResponse` results are closed by #64 ([[decisions/2026-10-21-fail-closed-redirects-and-hook-results]]) and are not listed. Each names its source and what blocks it. No item here needs a paid gateway call to write; only item 3 needs one to settle.

1. **Gateway path matching beyond the folded spellings.** Closed: the owner chose the fail-closed alternative in #70 on 2026-10-26. The hooks now run on every path except an exact list of the paths `@ai-sdk/gateway` uses for other calls and job reads, so a spelling the gateway might serve no longer needs to be known ([[decisions/2026-10-26-fail-closed-path-matching]], [[architecture/proxy]] step 6). The gateway's own routing stays unverified, and now only decides whether an unusual spelling of a real non-language-model call breaks a hook typed for language model calls.
2. **Hooks for non-language-model calls.** Closed: on the owner's #70 decision of 2026-10-26, embedding, image, video, speech, transcription, reranking, decision and batch start calls run the new optional `beforeRawRequest` and `afterRawResponse`, which receive the parsed body and the client response untyped ("Raw hooks" in [[architecture/proxy]]). Per-kind typed hooks are not built; they would need the gateway's response shapes, which item 3 leaves unobserved.
3. **Non-language model kinds are untested against the real gateway.** Open, tracked in #70 under #114: it needs a gateway key and paid calls, which are the owner's ([[decisions/2026-10-08-no-gateway-key-in-ci]]).
4. **Hook results are not validated.** Closed: on the owner's #70 decision of 2026-10-26, an `afterResponse` result with a missing or wrong-typed field is rejected, as an error naming the field on a non-streamed request (a 424 since [[decisions/2026-11-01-no-retry-after-answered-call]]) and by forwarding the original `finish` event on a stream ([[decisions/2026-10-26-strict-after-response-results]]). The check stops at the fields the proxy and the client read; the shape of each `content` part beyond its `type` is not checked.

Items 1, 2 and 4 were decided by the owner in #70 on 2026-10-26 and built in #73; item 3 remains open in #70.
