# Gaps after 0.2.0

Open unknowns found by reading [[architecture/proxy]] and [[architecture/streaming]] as of main b27079f, with #59 to #61 still open. Once those land, [[roadmap]] has no open item, so these are the candidates for the next round. Each names its source and what blocks it. No item here needs a paid gateway call to write; only item 4 needs one to settle.

1. **Gateway path matching beyond the folded spellings.** Once #59 lands, the `language-model` and batch read path checks fold case, percent-encoding, repeated and trailing slashes and `;` parameters. Whether the gateway routes any other spelling, or the same spellings as one route, is unverified, and a spelling the gateway serves but the fold misses would skip the hooks. Source: the #59 review caveat that the gateway's path match is unchecked, and the last lines of the decision note #59 adds, `decisions/2026-10-21-language-model-path-runs-hooks`. Blocker: the gateway docs or a recorded request, since probing it costs money. Until then the fold is the whole guarantee. The fail-closed alternative from the #59 review is to skip hooks only on known non-language model paths and batch reads, and run them everywhere else; it needs no gateway knowledge but changes which calls run hooks.
2. **Redirects from the gateway.** The proxy calls `fetch` with its default redirect handling, so a 307 or 308 from the gateway is followed with the method, body and same-origin `authorization` kept (a 301, 302 or 303 turns a POST into a bodyless GET), and the redirected path never meets `isSafePath` or the hook path checks. No test covers it. Source: the #59 review, which raised a trailing-slash 308. Blocker: none for a test with a fake gateway; the choice between `redirect: "manual"` and following is the owner's, since it changes behavior for a gateway that redirects.
3. **Hooks for non-language-model calls.** Embedding, image, video, speech, transcription, reranking, decision and batch start calls run no hook, so an operator cannot meter or audit them through the proxy. Source: step 6 of [[architecture/proxy]]. Blocker: the owner, since per-kind hook types are a public contract change; a first step is a hook that receives the raw request and response for those paths.
4. **Non-language model kinds are untested against the real gateway.** The keyless tests use fakes shaped after `@ai-sdk/gateway` 4.x, and `src/integration.test.ts` calls only `generateText` and `streamText`. Embedding, image, video and batch behavior through the proxy rests on reading the client, not on observed gateway responses. Source: [[development/testing]]. Blocker: a gateway key and paid calls, which are the owner's ([[decisions/2026-10-08-no-gateway-key-in-ci]]).
5. **Hook results are not validated.** An `afterResponse` result that is an object with missing or wrong-typed fields is serialised as returned, and on a stream the missing fields are left out of the rewritten `finish` event. Only `undefined` and `null` are caught. Source: "Hook result without stream metadata" in [[architecture/streaming]] and step 9 of [[architecture/proxy]]. Blocker: the owner, since rejecting such a result instead of forwarding it is a contract choice; fail-open with a log is the current behavior for `undefined` and `null`.

Update this note, and [[roadmap]] once it has items again, when an item lands.
